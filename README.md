A high-performance financial web app providing deep insights, candlestick visualizations, and quantitative analysis for stock market data.

## Overview
Objective: To build a trading visualization and analysis tool mimicking professional software.
Features: Dynamic date ranges, multiple tickers, and automated technical indicators.

## Tech Stack
Framework: Streamlit
Visualization: Plotly
Data Source: yfinance
