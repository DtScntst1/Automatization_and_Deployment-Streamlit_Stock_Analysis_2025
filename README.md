A financial web app with candlestick visualizations and quantitative analysis for stock market data.

## 💡 Overview
- **Objective:** Build a trading visualization tool mimicking professional software.
- **Features:** Dynamic date ranges, multiple tickers, and automated technical indicators.

## 🛠️ Tech Stack
- **Framework:** Streamlit
- **Visualization:** Plotly
- **Data Source:** yfinance
